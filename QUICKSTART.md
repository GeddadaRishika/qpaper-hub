# Quick start

1. Open a terminal in `qpaper-hub/backend`.
2. Copy `.env.example` to `.env`, set `JWT_SECRET` to a private random value, then run `npm install`, `npm run seed`, and `npm run dev`.
3. In a second terminal, open `qpaper-hub/frontend`, run `cp .env.example .env`, `npm install`, and `npm run dev`.
4. Visit http://localhost:5173.

See README.md for detailed setup, demo credentials, and API documentation.
