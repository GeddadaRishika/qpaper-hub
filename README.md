# QPaper Hub

QPaper Hub is a full-stack web application where students can browse, search, filter, save, and view previous question papers. Admins can upload and manage question papers.

## Live Website
https://qpaper-hub.vercel.app/

## Technologies Used

- **Frontend:** React.js, Vite, JavaScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** Supabase PostgreSQL
- **File Storage:** Supabase Storage
- **Authentication:** JWT (JSON Web Tokens)
- **API Requests:** Axios
- **Deployment:** Vercel (Frontend), Render (Backend)

## Features

- Student registration and login
- Browse and search question papers
- Filter papers by department, semester, subject, year, and exam type
- View and download question papers
- Save papers for later
- Admin dashboard to upload and manage papers
- Secure PDF storage
